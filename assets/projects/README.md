## Rules

- Do not recreate, approximate, recolor, or substitute a project logo when an authoritative project asset exists.
- Private implementation repositories remain private. Only the approved presentation asset is copied here.
- A project without a canonical standalone asset stays text-only in the profile until an approved asset exists.
- TITO PAR is intentionally text-only/not added to the generated portfolio set at this point because its repository currently documents branding but does not yet contain the final standalone logo asset or a profile PIO contract.
